# АЛА-ТОО · Жайлоодо кымыз

Лайн-арт ролик (стиль из `prompts/02-line-art.md`), 1920×1080, 30 fps, 14 секунд, со звуком.
Весь ролик — **одна непрерывная золотая линия** на тёмно-синем фоне. Никаких сторонних сервисов
и генерации картинок: картинка и звук целиком сделаны кодом.

**Сюжет:** линия рисует хребет Ала-Тоо → спускается в долину и становится юртой с тюндюком →
бежит по земле и превращается в старика-аксакала в калпаке, который сидит и держит кесе с кымызом.
Главный момент (9,5 с): линия превращается в заливку — калпак становится белым с узором «кочкор мүйүз»,
борода белеет, на вершинах загорается снег, в кесе появляется кымыз. Камера отъезжает, появляется надпись
«АЛА-ТОО · ЖАЙЛООДО КЫМЫЗ», и старик делает глоток кымыза.

| Время | Что происходит |
|---|---|
| 0,0–3,3 | линия рисует хребет Ала-Тоо |
| 3,3–6,2 | спуск в долину, юрта, тюндюк, дверь |
| 6,6–10,0 | старик: колени, рука с кесе, борода и лицо, калпак, спина |
| 9,55 | заливка: калпак, борода, снег, кымыз |
| 10,0–11,3 | отъезд камеры к итоговому кадру, надпись |
| 11,7–13,75 | старик пьёт кымыз; по линии пробегает свет |

## Как пересобрать

Нужны Node, ffmpeg, Python 3 (`numpy scipy numba soundfile pedalboard`) и Chromium из Playwright.

```bash
node demos/23-kymyz/dump_timing.mjs
```

```bash
python3 demos/23-kymyz/audio.py
```

```bash
node demos/23-kymyz/render.mjs
```

Готовое видео: `demos/23-kymyz/video.mp4`. Кадры для проверки: `node demos/23-kymyz/render.mjs --stills 1,5,9.6,13`.

Что поменять: тексты — функция `drawText` в `film.js`; длительность и тайминги — объект `CUES` в начале `film.js`;
цвета — `GOLD`, `MILK` и фон `#0B1320`.

Шрифт надписи: Inter (OFL), установлен в системе. Текстура зерна — из `assets/textures/grain` этого репозитория.
