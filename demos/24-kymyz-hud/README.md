# АЛА-ТОО // ЖАЙЛОО-СКАН

Та же история, что в `demos/23-kymyz`, но в стиле **киберпанк-HUD / FUI** (`prompts/22-hud.md`): 1920×1080, 30 fps,
12 секунд, со звуком. Картинка и звук сделаны кодом, без сторонних сервисов и генерации.

**Идея:** оптика-сканер «осматривает» жайлоо. Хребет Ала-Тоо собирается голограммой из контурных линий, радар крутится,
цифры бегут. Сканер находит юрту («ОБЪЕКТ 01 · БОЗ ҮЙ»), затем аксакала с кесе. Рамки захвата хватают цель —
интерфейс вспыхивает оранжевым: «ЦЕЛЬ ЗАХВАЧЕНА · КЫМЫЗ ОБНАРУЖЕН». В конце старик делает глоток, и телеметрия
показывает, что кымыза в кесе стало 62 %.

| Время | Что происходит |
|---|---|
| 0,0–0,5 | включение экрана, рамки, прицел, кольца |
| 0,2–2,3 | хребет Ала-Тоо собирается голограммой, журнал и телеметрия оживают |
| 2,3–3,9 | сканер спускается к юрте, метка «БОЗ ҮЙ» |
| 3,9–5,9 | сканер на аксакале, он прорисовывается лучом |
| 5,9–7,25 | рамки захвата ищут цель и сжимаются 1,4 → 1,0 |
| 7,4 | **захват**: оранжевая тревога, удар, глитч |
| 7,6–8,8 | камера отъезжает, общий план |
| 9,0–11,1 | глоток кымыза, «КЕСЕ · 62 %» |
| 10,6–12 | надпись «АЛА-ТОО · ЖАЙЛООДО КЫМЫЗ» |

## Как пересобрать

```bash
python3 demos/24-kymyz-hud/audio.py
```

```bash
node demos/24-kymyz-hud/render.mjs
```

Тайминги — `cues.json` (их читают и картинка, и звук). Тексты на экране — `film.js` (`LOG`, `drawRightPanel`, `drawLock`, `drawTitle`).
Шрифты: JetBrains Mono и Inter (OFL), установлены в системе.
